Move it until it looks right

Drag any block to move it, drag a corner to resize it, and copy the result out as CSS when the page finally sits the way you meant it to.

Drag

The whole box is the handle. Arrow keys nudge by a pixel, with Shift by ten.

Resize

Eight squares on the frame scale the block and everything in it, proportions kept. A double-click on one puts the box back.

Copy

Copy CSS for every change, or Copy params to brief a coding agent.
