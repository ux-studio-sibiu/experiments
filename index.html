UX Studio Sibiu

Experiments

Standalone front-end sketches. Each one is a single folder of plain HTML, CSS and JavaScript — no build step, no framework, open and run.

  • Background Experiments

    A browser for 86 tileable SVG patterns, with live controls for scale, opacity, colour tint and blend mode.

    /background-experiments
    • SVG
    • CSS
  • Color Palettes

    300 community palettes from Adobe Color, filterable by topic and tag, shown as stripes, a gradient or a sample layout — edit, reorder and shift the colours, then copy them as CSS variables, hex or JSON.

    /color-palletes
    • Color
    • CSS
  • Fluid hover

    A WebGL shader that smears an image toward the cursor — faster motion, stronger displacement, with chromatic aberration on the edges.

    /effect
    • WebGL
    • three.js
    • GLSL
  • Randomize Studio

    A type-pairing playground: editable heading, subheading and body over a background image, with ~40 Google Fonts swapped live and a dice roll for new combinations.

    /randomize-studio
    • Typography
    • Google Fonts
  • Paint

    MS Paint rebuilt in one file, bevels and all — a study in Windows 95 chrome with nothing but CSS borders.

    /paint-concept
    • Canvas
    • UI
  • Static background

    The animated film-grain overlay that fades in behind navigation menus. Canvas 2D, no dependencies, about 5 KB — noise is drawn into a downscaled buffer and stretched to fill.

    /static-background
    • Canvas
    • Motion
  • Icon Studio

    A studio for trying an icon out: pick one from the library, set its size, colour and the tile around it, and see the same icon at the sizes a real interface is built from.

    /icons
    • SVG
    • Icons
  • SVG Backgrounds

    A playground for the 48 free backgrounds from SVGBackgrounds.com: swap any colour inside the SVG, shift hue, saturation and lightness, rescale the tile, then copy the CSS.

    /svg-backgrounds
    • SVG
    • CSS
