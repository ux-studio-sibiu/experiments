Randomize Studio

design concepts : rapid prototyping : for designer-devs

  • editable design elements: layout, type, colour, image and texture
  • adobe-like ui for fast edits, layer based composition
  • output is json directly usable by coding-agents
  • use skills.md on existing projects to enable design edits in-browser

    • texture kit :

  2. 2Shift+T opens edit UI : randomize or manual edit
  3. 3serve changes as .json to coding-agent for lasting implementation
  4. 4prompt tool to self-remove from project

Adobe-like UI

  • layer based composition - show/hide each layer
  • floating inspector to adjust elements
  • drag, resize, edit text, directly on the artboard
  • randomize each layer - or randomize all

Modular

  • the studio wraps a few more specific, specialized tools
  • these can be used independently to handle: typography, texture, effects or layout edits
  • typography - fonts, sizing, and the text blocks themselves
  • texture - photographs, dynamic svg, patterns
  • effects - grain and other static fx, over everything else
  • layout - coming soon
  • the panel on this page is two of them - texture and effects - running on a page that is not the studio

Sources

  • fonts: google fonts
  • images: lorem picsum
  • svg backgrounds: svgbackgrounds.com
  • svg patterns: hero patterns
  • icons: dashicons
